기본 위젯 다루기 — 예제별 독립 Android 프로젝트

Android Studio에서 File > Open으로 Example3_1 폴더를 엽니다.
Gradle 동기화가 끝나면 app을 선택하고 에뮬레이터 또는 기기에서 실행합니다.
확인이 끝나면 같은 방법으로 Example3_2부터 Example3_6까지 순서대로 엽니다.
각 예제의 applicationId가 달라 같은 기기에 모두 설치할 수 있습니다.

예제 3-1 (PDF 3~4쪽)
  app/src/main/res/layout/activity_main.xml
  XML의 textColor, typeface, textSize로 Hello World!를 꾸밉니다.
  PDF 지시에 따라 크기는 50dp입니다. 일반적인 글자 크기는 sp를 사용합니다.

예제 3-2 (PDF 6~7쪽)
  app/src/main/java/com/example/example3_2/MainActivity.kt
  setText, setTextColor, setTypeface, setTextSize 메서드를 확인합니다.
  setTextSize(50f)의 기본 단위는 sp입니다.

예제 3-3 (PDF 9~10쪽)
  activity_main.xml의 android:onClick="showSum"과 MainActivity.kt를 함께 봅니다.
  버튼을 누르면 200 + 300의 합계 500이 토스트로 표시됩니다.

예제 3-4 (PDF 12~13쪽)
  다섯 EditText의 inputType을 확인합니다.
  성명, 숫자 비밀번호, 이메일, 생년월일, 연락처를 입력하고 결과보기를 누릅니다.
  PDF에 맞춰 비밀번호도 결과 텍스트에 출력하는 학습용 예제입니다.
  inputType은 키보드와 입력 형식을 지정하며 이메일 등의 유효성 검사는 하지 않습니다.

예제 3-5 (PDF 15~16쪽)
  drawable의 window.png를 배경 이미지로, cat1~cat5.png를 고양이로 표시합니다.
  다음보기를 5번 누르면 cat1.png로 돌아옵니다.

예제 3-6 (PDF 18~19쪽)
  예제 3-5의 Button을 ImageButton으로 바꿉니다.
  drawable/states.xml에서 눌림, 포커스/선택, 기본 상태 이미지를 지정합니다.
  터치하는 동안 눌림 이미지를, 키보드 Tab 등으로 포커스를 주면 포커스 이미지를 확인합니다.
  기본 항목은 조건 없는 마지막 item입니다.

환경: Kotlin 2.2.21, Android Gradle Plugin 8.13.2, Gradle 8.13,
      Android SDK 36.1, Build Tools 36.1.0, JDK 17 이상.
local.properties에는 이 컴퓨터의 SDK 경로가 들어 있습니다.
다른 컴퓨터에서는 Android Studio에서 해당 컴퓨터의 SDK 경로를 설정합니다.
